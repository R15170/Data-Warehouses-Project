# Implementations

This folder contains the implementations developed for the DrinkMix Data Warehouse project.

The implementation includes SQL and PL/SQL scripts for creating and working with the Data Warehouse, as well as Python code used for parts of the ETL process and database connection.

The work includes the creation of the Data Warehouse schema, data transformation and cleaning, customer and product integration, duplicate detection, and loading the transformed data into the Data Warehouse.

The implementation files correspond to the different practical tasks of the project.
