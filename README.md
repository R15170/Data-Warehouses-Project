# Data Warehouse Project – DrinkMix

This repository contains my work from the Data Warehouse practical project at university.

The project focuses on designing and implementing a Data Warehouse for a company called DrinkMix using data from different branch databases.

The project covers the analysis of heterogeneous source databases, data modelling, the design of a Star Schema, and the implementation of an ETL process for integrating and transforming the data.

## Main Topics

* Analysis of source databases
* Database schemas and E/R modelling
* Multidimensional Data Warehouse modelling
* mE/R modelling
* Star Schema
* PYTHON DATABASE LIBRARY
* Data cleaning and transformation
* Duplicate customer detection
* Product and customer data integration
* ETL process
* Data aggregation and reporting

The implementation also includes Python scripts used to connect to the database and support parts of the ETL process.

The repository contains the practical task documents as well as the implementations developed during the project.
